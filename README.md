# Briolin

Платформа для знакомств с элементами геймификации и психологического тестирования.

## О чём проект

**Briolin** — это не просто очередное приложение для знакомств. Мы добавили в него геймификацию, чтобы сделать поиск пары увлекательным, и психологический тест, который помогает лучше понять себя и свои ожидания от партнёра.

Пользователи проходят тест на готовность к отношениям, создают развёрнутый профиль с вопросами и ответами, а затем знакомятся через механизм «лайков» с ответами на вопросы. При взаимной симпатии создаётся матч и открывается чат с возможностью обмена сообщениями в реальном времени.

Проект построен на микросервисной архитектуре, что позволяет масштабировать отдельные компоненты и разрабатывать их независимо.

## Стек технологий

### Backend

- **Python 3.11 / 3.13** — основной язык
- **FastAPI** — веб-фреймворк для всех сервисов
- **PostgreSQL + asyncpg** — основная БД
- **MongoDB** — для хранения сообщений и тестовых сессий
- **Redis** — кэширование, хранение кодов верификации, онлайн-статусы
- **RabbitMQ** — асинхронное взаимодействие между сервисами (события)
- **Keycloak** — управление пользователями и аутентификация
- **MinIO** — S3-совместимое хранилище для медиафайлов (аватарки)
- **pgvector** — расширение PostgreSQL для поиска по эмбеддингам
- **sentence-transformers** — генерация эмбеддингов для рекомендаций

### Frontend

- **React + TypeScript** — основной фреймворк
- **Vite** — сборка
- **Tailwind CSS** — стилизация
- **Zustand** — управление состоянием
- **React Router v6** — навигация

### Инфраструктура

- **Docker + Docker Compose** — контейнеризация и оркестрация
- **Caddy** — веб-сервер и прокси для фронтенда и API

## Быстрый старт

Всё, что нужно для локального запуска — **Docker** и **Docker Compose**.

- Клонируйте репозиторий
git clone https://github.com/Babadzakkkich/briolin.git
cd briolin


- Настройте переменные окружения
Скопируйте примеры .env.example в .env для каждого сервиса:
исправьте на свои данные

- Запустите всё одной командой
docker-compose up -d --build
Это поднимет:

Все бэкенд-сервисы (на портах 8001–8008)

Базы данных (PostgreSQL, MongoDB)

Redis, RabbitMQ, MinIO, Keycloak

Фронтенд (через Vite dev-сервер)

Caddy (прокси на порту 80)

После запуска:

Фронтенд: http://localhost

API Gateway: http://localhost:8000/docs

Keycloak Admin: http://localhost:8080 (admin/admin)

MinIO Console: http://localhost:9001


## Структура проекта

briolin/
├── backend/                    # Все бэкенд-сервисы
│   ├── api-gateway/            # Точка входа, проксирует запросы
│   ├── auth-service/           # Аутентификация через Keycloak
│   ├── user-service/           # Управление пользователями
│   ├── profile-service/        # Профили и эмбеддинги
│   ├── matching-service/       # Лайки, матчи, рекомендации
│   ├── chat-service/           # Чаты и WebSocket
│   ├── media-service/          # Аватарки (MinIO)
│   ├── testing-service/        # Психологический тест
│   ├── email-service/          # Email-уведомления
│   └── shared/                 # Общий код (JWT, RabbitMQ, события)
├── frontend/                   # React-приложение
├── infrastructure/             # Инфраструктура
│   ├── caddy/                  # Конфиг Caddy
│   ├── keycloak/               # Realm для Keycloak
│   └── postgres/               # SQL-скрипты инициализации
├── scripts/                    # Вспомогательные скрипты
└── docker-compose.yml          # Оркестрация всех сервисов


Проект находится в стадии активной разработки.
